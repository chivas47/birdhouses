Meine Nistkästen

Noch keine Nistkästen.

Tippen Sie unten auf den grünen Knopf, um den ersten einzutragen.

1. Wo hängt der Nistkasten?

Schieben Sie die Karte, bis die Nadel auf der richtigen Stelle steht.

2. Machen Sie ein Foto vom Baum

So finden Sie den Nistkasten leichter wieder. Sie können das überspringen und später Fotos machen.

3. Geben Sie ihm einen Namen

Etwas, das Sie wiedererkennen, zum Beispiel „Große Eiche am Tor“.

An welchem Baum hängt er?

Wie ist der Nistkasten gerade in Schuss?

Wann haben Sie ihn aufgehängt?

Gespeichert!
